# Configuration, Manifest & Lockfile

Skillporter works with zero configuration flags and supports deterministic team configuration via `skillporter.yaml` and `skillporter.lock`.

## 1. `skillporter.yaml` (Project Manifest, Schema v2)

Initialize with `skillporter init`:

```yaml
schema_version: 2
project: my-service
scope: project
strategy: copy
security_policy: HIGH
security:
  policy: HIGH
  max_risk_score: 30
harnesses:
  - claude-code
  - codex
  - cursor
skills:
  - name: skillporter
    source: Shanmukh-l33t/skillporter/skills/skillporter
    ref: v3.0.0
    harnesses: [claude-code, codex, cursor]
```

## 2. `skillporter.lock` (Deterministic Lockfile, Schema v2)

Generated by `skillporter lock` or `skillporter sync` and verified in CI by `skillporter lock --check`:

```json
{
  "generated_at": "2026-11-14T08:00:00Z",
  "manifest_schema_version": 2,
  "reproducible": true,
  "schema_version": 2,
  "skills": {
    "skillporter": {
      "adapt": false,
      "adapter_version": "3.0.0",
      "dependencies": {},
      "direct": true,
      "file_hashes": {
        "SKILL.md": "8f91c2a0..."
      },
      "installed_targets": ["claude-code", "codex", "cursor"],
      "locked_at": "2026-11-14T08:00:00Z",
      "manifest_schema_version": 2,
      "name": "skillporter",
      "pin_state": "PINNED_COMMIT",
      "resolved_commit": "21ab0a07c87a08bbb6aaa6843e82b53468deb29f",
      "risk_score": 0,
      "scope": "project",
      "source": "https://github.com/Shanmukh-l33t/skillporter.git#skills/skillporter",
      "strategy": "copy",
      "tree_hash": "d6566139...",
      "version": "3.0.0"
    }
  }
}
```

`pin_state` distinguishes immutable `PINNED_COMMIT` and `PINNED_CONTENT` entries from `UNPINNED_MUTABLE` sources so `reproducible` is `true` only when every dependency is content-pinned.

## 3. Environment Variables

| Variable | Purpose | Default |
|---|---|---|
| `HERMES_HOME` | Hermes profile home used to resolve `$HERMES_HOME/skills` | `~/.hermes` |
| `SKILLPORTER_MCP_ROOT` | Explicit workspace boundary for `skillporter mcp` | `Path.cwd()` |
| `SKILLPORTER_MCP_ALLOW_WRITES` | Enable mutating MCP tools (`1` / `true`) | `0` (denied) |
| `SKILLPORTER_MCP_ALLOW_USER_SCOPE` | Enable MCP `scope="user"` reads (`1` / `true`) | `0` (denied) |
| `SKILLPORTER_OFFLINE` | Disable external scanner calls during `scan` (`1`) | `0` |
| `SKILLPORTER_REGISTRY_URL` | Optional local JSON path or HTTPS URL for custom registries | Seed catalog |
| `SKILLPORTER_TELEMETRY` | Opt-in anonymous local usage events (`1`) | `0` (disabled) |
| `DO_NOT_TRACK` | Unconditionally disable telemetry when `1` | Unset |
| `NO_COLOR` | Disable ANSI terminal colors when set | Unset |
