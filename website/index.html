        THE FRAGMENTATION PROBLEM
        
Every agent reads a different directory. Symlinks break. Copies drift.

      

      

        

          
Before Skillporter

          
    
            
  • Claude Code reads .claude/skills/ and ignores .agents/skills/.
    • 
            
  • Codex, Gemini CLI, and Zed read .agents/skills/ and ignore .claude/skills/.
    • 
            
  • Hand-made symlinks break inside Docker build contexts, git worktree, and Windows clones.
    • 
            
  • Copying into both .agents/skills/ and .cursor/skills/ makes Cursor load every skill twice.
    • 
            
  • Editing one copy leaves other harnesses silently running stale instructions.
    • 
          

        

        

          
With Skillporter v2.0

          
    
            
  • Smart Deduplication: Writes .agents/skills once for 14 compatible harnesses.
    • 
            
  • SHA-256 Drift Detection: Flags DRIFT in CI the moment two copies diverge.
    • 
            
  • Static Supply-Chain Gate: Scans for secrets, prompt injection, hidden Unicode, and curl | sh before install.
    • 
            
  • Deterministic Lockfile: Pins exact Git commits and SHA-256 tree hashes in skillporter.lock.
    • 
            
  • Transactional Rollback: Snapshots prior versions to .skillporter/backups/ for instant skillporter rollback.
    •

        SUPPLY-CHAIN PROTECTION
        
Treat third-party skills as untrusted code.

        
Skills inject instructions into your agent's context and ship executable scripts. Skillporter scans every file before installation.

      

      

        

          
Static Security Assessment (skillporter scan)

          
    
            
  • sec-prompt-override — Detects prompt-injection directives attempting to override system/user rules.
    • 
            
  • sec-hidden-unicode — Catches zero-width and bidirectional Unicode smuggling in SKILL.md.
    • 
            
  • sec-curl-pipe-sh & sec-reverse-shell — Flags RCE and raw socket payloads in scripts and Markdown.
    • 
            
  • sec-private-key, sec-aws-key, sec-github-token — Prevents committing or distributing leaked credentials.
    • 
            
  • sec-symlink-escape & sec-path-traversal — Blocks Zip-Slip, Tar-Slip, and symlinks resolving outside the skill root.
    • 
          

        

        

          
Explicit Trust Boundaries

          
    
            
  • Zero Script Execution: Cloning, unpacking, validating, and installing never execute bundled scripts.
    • 
            
  • Ownership Verification: Unmanaged directories are never overwritten without explicit --force.
    • 
            
  • Declarative Adapter SDK: Custom harness files (load_adapter_file) parse JSON data only—never arbitrary code.
    • 
            
  • Honest Labeling: Reports are explicitly marked STATIC_SECURITY_ASSESSMENT; static checks never claim runtime guarantees.
    •
